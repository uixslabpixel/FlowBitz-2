## Findings not planned (still open)

Kept from the audit so they are not re-discovered from scratch:

- Decrypted Text, Variable Proximity and Rotating Text write `textContent`
  back through `innerHTML`; Text Pressure empties its element on destroy.
- Every site page loads an unused three.js script (`Base.astro:49`); two
  decoration images of 8 MB and 4 MB are live on `/support` and the footer.
- About 4,000 lines of pre-Astro JSX are unreachable; several packages are
  unused; `prismjs` is imported but not declared; site packages sit in
  `dependencies` of the published package.
- Canvas backgrounds rebuild after `destroyAll()`, run offscreen, ignore
  `devicePixelRatio`; Firefly and Matrix Rain ignore reduced motion.
- The loader fetches GSAP from a CDN (unpinned) although the build bundles it.
- Docs drift: `wb-max-iteration` (metadata) vs `wb-max-iterations` (code);
  README's `init({ components })` is ignored; "Node 16+" is wrong.
- Every route ships the whole site in one `client:only` island.
- `WebflowBits.js` (showcase and beta only): no destroy for Firefly/Shimmer,
  a 3D-card helper that calls Smart Animate, a possible rebuild loop for
  Matrix Rain and Dot Grid.
- `src/library/data/componentsRegistry.js` has a broken path map; whether to
  fix or delete it depends on the "one registry" direction below.

Direction options raised, undecided: one generated component registry (or
retiring `WebflowBits.js`); types and attribute snippets from the metadata;
finishing the template purchase flow; library-wide reduced motion and
pause/resume.
